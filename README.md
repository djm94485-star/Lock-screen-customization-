# Clock Resizer (LSPosed module, Android 16, arm64)
Build: open in Android Studio -> Build APK. Install, enable in LSPosed, scope = System UI, restart System UI.
Use: long-press lock screen clock -> white box appears.
 - drag inside box = move
 - drag a side (dot) = resize only that axis (left/right = width, top/bottom = height)
 - double-tap = reset, tap outside = done
Original clock styles / fonts / depth / color remain untouched (module only scales + translates the clock container).
